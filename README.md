# Abraham Huitron — Interactive Analytics Portfolio & Web Resume (`www.abrahamhuitron.com`)

Source repository for **[www.abrahamhuitron.com](https://www.abrahamhuitron.com)** — an analytics-inspired portfolio, Power BI architecture showcase, and interactive web resume for **Abraham Huitron** (Senior Data Analyst & Analytics Specialist, M.S. in Data Science).

## Highlights & Features
- **Analytics-Inspired Dual-Theme UI**: Dark & Light mode toggle (`localStorage` persisted) with an executive 3×2 KPI dashboard strip and a 3-way interactive profile photo switcher (`Executive | Illustrated | Casual`).
- **Power BI & Backend Architecture Case Studies (`#projects`)**:
  - High-resolution enterprise dashboard previews with a full-screen **Lightbox** viewer.
  - Expandable **"Under the Hood"** technical drawers documenting **Kimball Star-Schema & Cross-Database Constellation models**, **semi-additive DAX time-intelligence measures**, and **parameterized Power Query (M) incremental refresh pipelines**.
- **Interactive Experience & Skill Highlighting (`#experience` & `#skills`)**:
  - Filter career timeline roles by focus area (`Power BI & Storytelling`, `SQL, Python & AI`, `Leadership & Instruction`), including an expandable 400-hour boot camp curriculum drawer for Pepperdine University & UNLV instruction.
  - Click any skill pill in the **Skills & Core Competencies** matrix to dynamically highlight matching tags across Experience, Projects, and CSUF Graduate/Undergraduate Coursework.
- **Verified Manager Endorsements (`#reviews`)**: Highlights consecutive UnitedHealth Group annual performance evaluations culminating in a `5 / 5 — Exceeds Expectations` rating.
- **Print / Save as PDF Engine (`@media print`)**: Dedicated print stylesheet that formats the live site into a clean, ATS-ready executive PDF resume on demand.
